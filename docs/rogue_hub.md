# Rogue Hub, abilities and randomizer

## The hub

New games skip the truck intro and start in the **Rogue Hub** (`MAP_ROGUE_HUB`). It reuses Littleroot's layout but has no connections and no warps, so it's a closed town. You get the Pokédex and Running Shoes on arrival.

People in the hub:

| Who | Where | What they do |
|-----|-------|--------------|
| Scientist | South, by the lab door | Starts runs |
| Builder | Centre | Spends Rogue Coins on areas |
| Storage | North-west | Opens the PC |
| Sign | East | Shows coins and best wave |

Areas you can build with Rogue Coins, like Emerald Rogue's hub upgrades. Each one replaces a hiker standing on a construction site:

| Area | Cost | Effect |
|------|------|--------|
| Poké Mart | 300 | Balls, potions, Full Heal, Revive, Ether, evolution stones |
| Healer | 600 | Full heal between runs |
| Move Tutor | 400 | Relearn any level-up move for a Pokémon in the PC or party |
| Ability Lab | 800 | Switch a Pokémon's regular ability between its 3 slots |
| Supply Depot (3 levels) | 300 / 700 / 1,200 | Items at the start of each run: balls and Super Potions, then Great Balls and Revives, then Rare Candies and a Full Restore |
| Draft Office (3 levels) | 400 / 900 / 1,600 | +2 draft points per level |

Building reloads the hub so the new area appears straight away.

## Four abilities per Pokémon

Every Pokémon has one regular ability (picked from its ability slots, swappable at the Ability Lab) plus **3 innates** that are always active, as in Elite Redux. On the summary's Info page, press **SELECT** to step through all four: name, "Innate:" marker, a 1/4 counter and the description.

Both lists come from each species' real ability data, generated by `dev_scripts/elite_redux/gen_innates.py` into `src/data/pokemon/innates.h`:

1. Elite Redux's innates where the expansion has that ability.
2. The species' own regular and hidden abilities.
3. Abilities from the rest of its evolution family and alternate forms.
4. Common abilities for its type, as a last resort (signature abilities like Wonder Guard or Multitype are never handed out this way).

Regular slots and innates never overlap, so the four are always distinct. About 38% of Elite Redux's innates are abilities that only exist in Elite Redux, which is why many Pokémon previously had fewer than four; those slots are now filled from the sources above.

Innates also work outside battle: Pickup, Honey Gather, Synchronize, Cute Charm, Flame Body/Magma Armor hatching, Static/Magnet Pull encounters, Stench, Illuminate, Arena Trap, Intimidate, Keen Eye, Compound Eyes, Super Luck, Suction Cups, Swarm and the rest all check innates through `MonHasAbility()`.

## Randomizer

Options menu, page 2 (press **L** or **R**). Each option can be turned on separately and they're off by default:

| Option | What changes |
|--------|--------------|
| Abilities | Each species' regular ability slots |
| Innates | Each species' 3 innates (always 3 distinct) |
| Types | Random types; mono-type stays mono, dual stays dual |
| Level-up moves | Same levels, random moves; the first move is always an attack |
| Base stats | Shuffled between stats, total kept |
| Run Pokémon | Wild run waves use any non-legendary first stage |

Randomization is deterministic per save (a seed made the first time an option is turned on), so a species always gets the same result in that save. Turning an option off restores the real data. Unswappable abilities (Multitype, Zen Mode, Wonder Guard, Truant and similar) are never handed out.

Options picked from the title-screen Options menu before New Game carry over into the new save.

## Unimplemented content

The engine has no move left on `EFFECT_PLACEHOLDER`. The only ability marked unimplemented was **Aura Guard** (Mega Lucario Z): it now halves damage from contact moves and isn't bypassed by Mold Breaker.
